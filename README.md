# 極限操控方塊 V2.0.1

## 更新重點
- 將「清除 / 改輸入」改為「本機玩家帳號清單」。
- 新增本機玩家帳號清單彈窗，列出目前這台裝置 / 瀏覽器可登入玩家。
- 帳號清單可快速帶入玩家帳號，接著輸入挑戰密碼即可登入。
- 帳號欄仍保留自由輸入，不強迫只能選清單。
- 登入時若帳號不存在，系統會明確告知並引導查看本機玩家帳號清單。
- 登入時若玩家已封存，系統會引導至本機資料管理中心恢復。
- 登入時若密碼錯誤，系統會明確告知密碼錯誤，並顯示密碼提示或引導查看提示。
- 帳號空白、密碼空白、帳號不存在、帳號封存、密碼錯誤、登入成功都會在登入區有明確回饋。
- 同步更新新手村指引、產品說明、版本歷程與版權版本號碼。
