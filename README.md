# 極限操控方塊 V2.0.4

## 緊急修正重點
- 修正 V2.0.2 可能造成龍虎榜空白的 JavaScript 顯示錯誤。
- 補上 getLeaderboard 與 renderLeaderboards，避免排行榜渲染函式缺失。
- 龍虎榜載入時會從三個來源合併資料：
  1. 既有本機龍虎榜紀錄
  2. 玩家帳號資料中的 bestScore / bestLevel
  3. 玩家正式存檔中的 score / level / lines
- 若本機龍虎榜曾被寫成空陣列，但玩家資料仍在，系統會自動重建真實玩家榜單。
- 儲存龍虎榜前會先備份舊資料至 backup key。
- 新增「本機資料管理 → 修復 / 重建龍虎榜」按鈕。
- 修復只處理真實玩家紀錄，不會把預設挑戰者寫成真實玩家。
- 保留 V2.0.3 的真實玩家 / 預設挑戰者高對比識別。
- 同步更新新手村指引、產品說明、版本歷程與版權版本號碼。
