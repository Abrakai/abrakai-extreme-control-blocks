# 極限操控方塊 V1.9.8

## 更新重點
- 修正玩家帳號欄位的輸入體驗。
- 玩家帳號現在可自由輸入，也可從本機挑戰者清單快速帶入。
- 新增「清除 / 改輸入」按鈕，方便切換到其他玩家帳號。
- 修正 selectedPlayerId 可能造成舊玩家選取狀態卡住、導致輸入其他帳號卻無法登入的問題。
- 新增登入引導文字，說明清單只是輔助，不是強迫只能選清單。
- 特別感謝改為「提供遊戲體驗建議與遊戲創意點子」。
- 版權與產品介紹中的「產品介紹」改為正式產品說明，不再放版本修正事項。
- 版本修正事項統一放在產品更新歷程。
- 同步更新新手村指引、產品說明、版本歷程與版權版本號碼。
