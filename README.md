# 極限操控方塊 V2.1.6

## 修正重點
- 將「清空帳號欄」改為「清空登入欄位」，避免誤會成清除玩家資料。
- 清空登入欄位只會清掉首頁玩家帳號輸入框、挑戰密碼輸入框與目前帶入狀態。
- 清空時會移除 remembered current player，避免清完後又自動跑出上一位玩家名稱。
- 清空不會刪除任何玩家帳號、挑戰密碼、最高紀錄、存檔或龍虎榜資料。
- 本機玩家帳號清單說明已補充「帶入帳號」與「清空登入欄位」的差異。
- 登入欄位加上 autocomplete="off"，降低手機瀏覽器自動補回舊帳號的機率。
- 保留 V2.1.5 註冊登入完全分流。
- 通過 JavaScript 語法檢查。
