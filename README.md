# 極限操控方塊 V2.0.2

## 更新重點
- 登入成功後會直接進入遊戲，提示改為「驗證成功，正在進入遊戲」。
- 密碼欄按 Enter 也可以直接開始挑戰。
- 移除首頁內嵌的「本機挑戰者清單」，避免重複佔據首頁空間。
- 「本機玩家帳號清單」按鈕保留，作為查詢與快速帶入帳號的主要入口。
- 阿布拉.凱不再作為本機預設玩家帳號，只保留在預設龍虎榜中。
- 舊版本若曾留下空白的「阿布拉.凱」本機玩家資料，系統會自動清理。
- 預設龍虎榜加入動態成長機制：預設玩家會依真實玩家實力微幅提升，但不會超越已在前方的真實玩家。
- 預設龍虎榜不會被存成真實玩家紀錄，避免擠掉真實玩家資料。
- 阿布拉.凱預設龍虎榜分數已提高，保持預設榜首挑戰目標。
- 同步更新新手村指引、產品說明、版本歷程與版權版本號碼。
