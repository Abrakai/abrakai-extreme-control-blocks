# 極限操控方塊 V2.1.4

## 修正重點
- 修正同一位真實玩家在龍虎榜重複佔據多個名次的問題。
- 同一 playerId 只保留最高分紀錄。
- 舊版沒有 playerId 的紀錄會退回用玩家名稱合併，避免同名真實玩家舊紀錄洗版。
- 合併時保留最佳紀錄：最高分優先；同分時比較 Level、消行數、時間。
- saveLocalLeaderboard 只保存去重後的真實玩家紀錄。
- submitScoreToCloud 結算後會立即去重，不再每次結算都新增一筆名次。
- 本機資料管理新增「合併重複玩家名次」手動修復按鈕。
- 預設挑戰者仍保留，但不會和真實玩家紀錄混合合併。
- 不會刪除玩家帳號、挑戰密碼、最高紀錄、存檔或龍虎榜資料。
- 通過 JavaScript 語法檢查。
