# 極限操控方塊 V2.0.5

## 緊急修正重點
- 修正 V2.0.4 的初始化順序錯誤。
- 避免 JavaScript 模組在啟動時中斷，造成首頁、玩家帳號、本機資料管理與龍虎榜都無法正常運作。
- 龍虎榜不再於系統常數尚未建立前載入。
- 啟動後會自動從既有龍虎榜、玩家帳號資料與正式存檔重建榜單。
- 本機資料管理新增「檢查本機資料狀態」。
- 保留「修復 / 重建龍虎榜」功能。
- 儲存龍虎榜前仍會先備份舊資料。
- 同步更新新手村指引、產品說明、版本歷程與版權版本號碼。

## 重要說明
V2.0.4 的問題是程式啟動中斷，導致資料看起來消失；不是主動刪除玩家帳號或成績。
只要使用者沒有清除瀏覽器網站資料、沒有永久刪除玩家、沒有換瀏覽器或裝置，玩家資料仍有機會被 V2.0.5 自動讀回。
